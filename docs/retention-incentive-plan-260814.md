# 위븐 핵심인력 리텐션 제도 수행안 (제안)

**작성일: 2026-08-14 · 상태: Draft — 대표 검토 후 확정**

> 목적: 투자자 질의 "내부 인력풀은 충분한가 — 리텐션 패키지 세팅"에 대해 **문서로 증빙 가능한 상태**를 만드는 것.
> 현황 전제: ① 스톡옵션 **부여 완료** ② 직무발명보상 **초안/구두 운영 중** ③ 성과 인센티브 **부분 운영 중**.
> 원칙: 이미 있는 것은 "정식 문서화", 없는 것은 "라운드 전 제정" — 실사에서 요구받기 전에 선제 완비.

## 1. 직무발명보상규정 — 정식 제정 (최우선)

현재 구두/초안 운영 중이므로, **이번 라운드 전 정식 제정**이 목표입니다. 덱에도 "이번 라운드 전 이사회 결의로 정식 규정화"로 표기해 두었습니다 — 이 일정을 지키면 덱과 실사 문서가 일치합니다.

### 1-1. 제정 절차 (발명진흥법 기준)

| 순서 | 절차 | 기한(안) | 비고 |
|---|---|---|---|
| 1 | 규정 초안 작성 — 특허청 「직무발명보상규정 표준모델」 기반으로 자사화 | 8월 3주 | 표준모델은 특허청/한국발명진흥회 배포본 사용 |
| 2 | **종업원 협의·동의 절차** — 규정안 사내 공개 + 종업원 과반 의견 수렴 | 8월 4주 | 발명진흥법상 보상 기준 결정 시 종업원과의 협의 필요. 협의 이력(회의록·동의서)을 남길 것 |
| 3 | 이사회 결의 | 9월 초 | 결의서 원본 보관 — 실사 제출 문서 |
| 4 | 사내 공표 + 발명신고 양식 배포 | 9월 초 | 그룹웨어/노션 게시 |
| 5 | 기존 출원 특허에 소급 적용 결의 | 9월 초 | 기존 특허 발명자(팀원)에게 출원 보상 소급 지급 — 리텐션 효과 즉시 발생 |

### 1-2. 보상 테이블 (제안 — 금액은 대표 조정)

| 보상 유형 | 시점 | 제안 금액 | 비고 |
|---|---|---|---|
| 발명 신고 보상 | 발명 신고·승계 시 | 발명 1건당 10만원 | 신고 유인용 소액 |
| 출원 보상 | 특허 출원 시 | 국내 50만원 / PCT·해외 100만원 (발명자 배분) | 공동발명자는 기여율 배분 |
| 등록 보상 | 특허 등록 시 | 국내 100만원 / 해외 200만원 | |
| 실시 보상 | 특허가 제품·매출에 실시된 경우 | 연 단위 산정, 실시 수익 기여분의 3~5% (상한 설정) | 발명심의위원회가 연 1회 산정 |
| 처분 보상 | 특허 양도·라이선스 수익 발생 시 | 처분 수익의 10~15% | |
| 출원유보 보상 | 영업비밀로 유보 결정 시 | 출원 보상에 준함 | 유보해도 보상 — 신고 유인 유지 |

**세무 포인트**: 직무발명보상금은 소득세법상 비과세 한도(현행 연 700만원)가 있어 같은 금액이라도 급여·상여보다 실수령이 큽니다. 지급 시 비과세 항목으로 처리하도록 세무사에 확인. ※한도·요건은 지급 시점 세법 재확인 필요.

### 1-3. 운영 체계

- **발명심의위원회**: 대표(위원장) + CTO + 해당 부서장 1인. 발명 신고 접수 → 승계/유보 결정(신고 후 4개월 내) → 보상 산정.
- **발명 신고 양식**: 발명 명칭·내용·발명자·기여율 — 1페이지 표준 양식.
- **실사 대응**: 규정 원문 + 이사회 결의서 + 소급 지급 내역이 세트로 제출되면 "체계가 실제 작동한다"는 증거가 됩니다.

## 2. 스톡옵션 — 부여 완료 상태의 고도화

부여는 완료되었으므로, 수행안의 초점은 **문서 정비 + 후속 부여 사이클 설계**입니다.

### 2-1. 실사 대비 문서 정비 (즉시)

| 문서 | 내용 | 상태 확인 |
|---|---|---|
| 스톡옵션 부여 내역표 | 대상자·수량·행사가·부여일·베스팅 스케줄 | 주주명부와 정합 확인 |
| Fully Diluted 주주명부 | 스톡옵션 전량 행사 가정 지분표 | 자문 제출 예정 자료와 동일본 유지 |
| 주총 결의서 | 부여 근거 결의 (상법상 주총 특별결의) | 원본 스캔 보관 |
| 부여 계약서 | 개인별 계약 — 베스팅·퇴사 시 처리 조항 포함 여부 확인 | 조항 누락 시 보완 계약 |

**벤처기업 특례 확인**: 벤처기업 인증 상태라면 행사이익 과세특례(비과세 한도) 및 시가 이하 행사가 부여 특례 적용 가능 — 부여 시 특례 요건을 충족했는지 회계사 확인 후, 실사 질의 대비 메모 1장 작성.

### 2-2. 후속 부여 사이클 (제안)

- **신규 핵심 채용용 풀**: 이번 라운드 채용(ML 엔지니어·그로스 마케터 등) 오퍼에 스톡옵션 포함 — 총발행주식의 10% 이내에서 풀 유지.
- **표준 조건**: 4년 베스팅 / 1년 클리프 / 이후 분기 단위. 기존 부여분과 조건 통일.
- **리프레시 그랜트**: 근속 2년+ 핵심 인력 대상 추가 부여 사이클(연 1회 심사) — "초기 부여 소진 후 이탈" 리스크 방어.

## 3. 성과 인센티브 — 부분 운영을 제도로

이미 어느 정도 운영 중인 것을 **KPI 연동 규칙**으로 문서화합니다. 덱의 "구독 MRR 단일 KPI" 메시지와 연동하면 투자자에게 일관된 인상을 줍니다.

### 3-1. 구조 (제안)

| 층위 | 제도 | 재원·기준 | 주기 |
|---|---|---|---|
| 전사 | 연간 성과급 | 연간 구독 MRR 목표 달성률 100% 이상 시 인센티브 풀 조성 (예: 목표 초과 이익의 20%) | 연 1회 |
| 팀/개인 | 스팟 보너스 | 마일스톤 단위 (예: 일본 론칭, MS Marketplace 등록, 논문 게재) 건당 정액 | 수시 |
| 기술 성과 | 직무발명보상 | 1장의 규정으로 별도 운영 — 성과급과 중복 지급 가능함을 명시 | 규정 따름 |

### 3-2. 설계 원칙

- **재원 연동**: 인센티브 풀은 구독 MRR 달성률에 연동 — "보상도 구독 곡선을 향한다"는 메시지로 덱 KPI 원칙과 일치.
- **분리 명시**: 직무발명보상(법정 성격)과 성과 인센티브(재량 성격)는 별개 — 중복 수령 가능함을 규정에 명시해야 특허 신고 유인이 살아 있습니다.
- **문서화**: 취업규칙 또는 별도 "보상 규정" 부속으로 1~2페이지면 충분. 겸업·경업금지 조항이 취업규칙에 있는지 이번에 함께 점검.
