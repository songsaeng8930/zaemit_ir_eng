> **다른 지침과의 관계**: [ir-copy-style-guide.md](ir-copy-style-guide.md)(한국어 화법·슬롭 금지)와 [blog-copy-style-guide.md](blog-copy-style-guide.md)(블로그 산문 어투)는 어투 지침으로 계속 유효하다. 이 문서는 **문장의 구조와 형식**(헤드라인·서브·카드·불릿·숫자·이력 표기)을 규정한다. 충돌 시 이 문서가 우선한다.

## 1. 원문 채록 (Corpus)

문장체의 정답지. 새 문서 작성 시 이 채록에서 같은 위치의 문장을 찾아 구조를 그대로 따른다.

### P1 — 커버/개요

- 배지: `LIVING DB POWERED`
- 헤드라인: **Hyper-Personalized / Web Operations Platform** (2줄, 뒷줄 없음·전체 흰색)
- 서브: "We turn static websites into intelligent, self-operating services. Upload HTML from any vibe-coding tool — our AI handles the rest: personalization, optimization, and 24/7 autonomous operation."
- 지표 밴드: `$1.1M Annual Revenue` · `625% YoY Growth` · `28 Patents` · `25 Team`
- 라벨: `STRATEGIC PARTNERS & GLOBAL NETWORK` → 칩: NHN / Naver / Azure / AhnLab / `US USA MOU 12 · LOI 4` / `JP Japan MOU 3` / `IN India 1 · CN China 1`
- 카드 `KEY METRICS`: $2.1M 2026 Target / 200% Growth Target / $10.7M Valuation / $1.4M Pre-A Raising
- 카드 `THE PROBLEM WE SOLVE`:
  - "**Vibe coding creates**, but **can't operate**"
  - "Manual updates **costly** for SMBs"
  - "**No personalization** for visitors"
  - "**80%** of websites abandoned in 6 months"
- 푸터: "James Kim, Ph.D | CEO & Founder | kjh@weven.kr | LinkedIn"

### P2 — 솔루션

- 라벨: `OUR SOLUTION`
- 헤드라인: **From Any HTML to / Self-Operating Service** (뒷줄 강조색)
- 서브: "Whether from **Vibe Coding** (Claude, Cursor, v0) or **Pro Web Editors** (Z.STUDIO, Webflow) — our AI platform transforms static output into living, intelligent web services."
- 카드 3장 (제목 + 본문 한 문장):
  - **Any Source, One Platform** — "Upload HTML from Vibe Coding tools (Claude Artifacts, Cursor, v0, Bolt) or professional editors (Z.STUDIO, Webflow, Framer)."
  - **RAG-Based AI Engine** — "Retrieval-Augmented Generation provides context-aware responses and personalized content for each visitor."
  - **Auto-Operation 24/7** — "Automated content updates, A/B testing, and conversion optimization — no coding or manual work required."
- 다이어그램: Vibe Coding (Claude · Cursor · v0 · Bolt) + Pro Editors (Z.STUDIO · Webflow · Framer) → **Zaemit AI Platform** → Self-Operating Web Service. 캡션: "Static → Intelligent in minutes"

### P3 — 트랙션 & 시장

- 라벨: `TRACTION & MARKET`
- 헤드라인: **20K Monthly Visitors, / 10% Conversion Rate** (지표가 곧 제목, 뒷줄 강조색)
- 지표 밴드: 20K Monthly Unique Visitors / 10% Conversion Rate / 30% Retention Rate / $14K Monthly B2C Revenue
- 차트: "Monthly Unique Visitors (MUV) — Dec 2025" + 주석 핀 "Dec 2025 · 20K MUV" + 하단 $1.1M Annual Revenue '25 / 625% B2C Growth / 28 Patents Filed
- 카드 **Why Now?** (질문형 제목 — 덱 전체 1회):
  - 리드: "Vibe coding and AI tools can **create** websites — but they can't **operate** them."
  - "2.1 billion websites globally, 65% built with No-Code/Low-Code"
  - "Post-AI era births a new paradigm: Vibe Coding"
  - "Static output needs intelligent operation layer"
  - "We are that AI layer — transform static → living services"
  - `Market Opportunity`: $267B TAM · $48B SAM · $850M SOM

### P4 — 글로벌 확장

- 라벨: `GLOBAL EXPANSION`
- 헤드라인: **Expanding Globally with / Strategic Partnerships** (뒷줄 강조색)
- 서브: "GS Certified · TIPS · NAVER Cloud · NHN · AhnLab · Infobank — Strong domestic foundation for global growth"
- 딜 카드 (상태 배지 + 한 문장 + 조건 각주):

  - 배지 `In Progress` `MY` — "Pursuing Hosting Rental Pack cooperation with Humming Software" / "Discussing cooperation with Malaysian enterprise"
- 국가 카드 (국기코드 + 활동 명사구 불릿, 마침표 없음):
  - `JP Japan`: Startup-JAPAN · JETRO IR · Climbers Startup EXPO · K-ICT WEEK · Rakuten Visit · DG Daiwa Ventures IR · Local MOU Negotiation · Yui-System Studio Co. MOU

- 라벨: `TEAM & INVESTMENT`
- 헤드라인: **Experienced Team, / Clear Path Forward** (뒷줄 강조색)

## 2. 추출된 문장체 규칙

### A. 헤드라인 — 명사구 2줄, 뒷줄이 핵심

완결 문장을 쓰지 않는다. 두 줄로 나누고 뒷줄(강조색)에 핵심을 놓는다. 이 덱의 헤드라인 유형은 4가지뿐이다:

| 유형 | 구조 | 원문 예 |
|------|------|---------|
| 정체성형 | 수식어 + 카테고리 명사구 | Hyper-Personalized / Web Operations Platform |
| 변환형 | From A to B | From Any HTML to / Self-Operating Service |
| 지표형 | 숫자 + 지표명, 숫자 + 지표명 | 20K Monthly Visitors, / 10% Conversion Rate |
| 자산-방향형 | 현재 자산, 다음 방향 | Experienced Team, / Clear Path Forward |

- 지표가 강력하면 **숫자 자체를 제목으로** 쓴다 (지표형).
- 진행형 동명사 허용: "Expanding Globally with Strategic Partnerships".
- 장식 형용사·최상급 없음. 수식어는 기능어만 (Hyper-Personalized, Self-Operating, Experienced).

### B. 서브타이틀 — 단정 1문장 + 흐름 1문장

- 첫 문장: 주어(We/제품)가 하는 일을 현재형으로 단정 — "We turn static websites into intelligent, self-operating services."
- 둘째 문장(선택): 사용 흐름 — "Upload HTML from any vibe-coding tool — our AI handles the rest: …"
- **대시(—) 부연 + 콜론(:) 뒤 3항 나열** 리듬: "…the rest: personalization, optimization, and 24/7 autonomous operation."
- 핵심어 볼드 + 괄호 안 실물 고유명사: "**Vibe Coding** (Claude, Cursor, v0)".
- 고유명사 신뢰 체인: 가운뎃점(·)으로 잇고 대시로 요약 — "GS Certified · TIPS · NAVER Cloud · NHN · AhnLab · Infobank — Strong domestic foundation for global growth".

### C. 카드 — 명사구 제목 + 정확히 한 문장

- 제목: 2~4단어 명사구. 패턴 두 가지 — 콤마 페어("Any Source, One Platform") 또는 기술명+숫자("Auto-Operation 24/7").
- 본문: **한 문장**. 괄호 실물 예시를 넣고, 필요하면 문장 끝 대시로 이득을 요약 — "— no coding or manual work required."
- 질문형 제목("Why Now?")은 투자자 관용구에 한해 덱 전체 1회.

### D. 불릿 — 마침표 없는 전신문, 숫자 선행

- 완결문이 아닌 압축문으로 쓰고 마침표를 찍지 않는다 — "Static output needs intelligent operation layer".
- 숫자를 문두에: "2.1 billion websites globally, 65% built with No-Code/Low-Code".
- 문제 불릿은 동사 대 동사의 대조 압축: "**Vibe coding creates**, but **can't operate**" — 볼드는 대조되는 동사에만.
- 상태 전환 화살표(→) 허용: "transform static → living services", "Static → Intelligent in minutes". ※ 문서·슬라이드 한정. 블로그 산문에서는 금지 유지.

### E. 숫자 — 모든 주장에 지표, 큰 숫자 + 작은 라벨

- 숫자는 크게, 라벨은 그 아래 작게: `$1.1M` / `Annual Revenue`.
- **4지표 밴드**가 기본 단위 — 커버, 트랙션, 글로벌 합계, THE ASK 모두 지표 4개 구성.
- 축약 표기 통일: $1.1M, 20K, $5B+, 10+ years, 5+ Countries. "+"로 하한 표시.
- 시점 명기: Annual Revenue **'25**, **2026** Target, **Dec 2025** 주석 핀.

### F. 증거·이력 — 조각 체인, 상태 배지, 정직한 각주

- 경력은 완결문이 아니라 가운뎃점(•) 조각 체인: "Korea Univ. MBA • Ex-CEO BlueStream (9 yrs) • Web Award Korea Grand Prize • 7 published papers" — 학력 → 경력(연차) → 수상 → 산출물 순.
- 확신 수위는 배지로: `NDA` / `In Progress` / `(Planned)`. 완료·진행·계획을 표기로 구분하고 본문에서 부풀리지 않는다.
- 말 못 하는 것은 숨기지 말고 명시: "Details confidential".

### G. 섹션 라벨 — ALL CAPS 짧은 명사

`OUR SOLUTION` / `TRACTION & MARKET` / `GLOBAL EXPANSION` / `TEAM & INVESTMENT` / `THE ASK` / `THE PROBLEM WE SOLVE` / `KEY METRICS` — 전치사 없는 명사(구), 최대 4단어.

### H. 어휘

- 동사: turn, transform, provide, handle, upload — 실행 동사만. 은유 동사 없음.
- 형용사: intelligent, self-operating, context-aware, automated — 기능 서술만. revolutionary/world-class류 장식 최상급 없음.
- 콘셉트 용어는 만들어서 **일관 반복**: "living services", "Self-Operating Web Service", "LIVING DB". 한 덱 안에서 표기를 바꾸지 않는다.

## 3. 한국어 문서 적용 매핑

영문 원본의 구조를 한국어 문서에 옮길 때의 대응:

| 요소 | 영문 원본 | 한국어 적용 |
|------|-----------|------------|
| 헤드라인 | 명사구 2줄 | 명사구 2줄 유지 — "초개인화 / 웹 운영 플랫폼". 서술형 제목 금지 |
| 서브 첫 문장 | We turn A into B. | "저희는 A를 B로 바꿉니다." — 현재형 단정, 합니다체 |
| 카드 본문 | 한 문장 + 괄호 예시 | 한 문장 + 괄호 예시 동일 — "(클로드, 커서, v0)" |
| 불릿 | 마침표 없는 전신문 | 명사형 종결, 마침표 없음 — "정적 결과물에 지능형 운영 레이어 필요" |
| 대조 압축 | creates, but can't operate | "만들 수는 있지만, 운영은 못 합니다" — 동사 대조만 볼드 |
| 이력 체인 | • 조각 체인 | 동일 — "고려대 MBA • 블루스트림 대표 9년 • 웹어워드코리아 대상" |
| 숫자 표기 | $1.1M, 20K | 한국어 문서는 "11억", "2만" — 단, 글로벌 문서는 $ 표기 유지 |

어투(슬롭 금지, 확신 수위, 근거+결론)는 [ir-copy-style-guide.md](ir-copy-style-guide.md)를 그대로 적용한다.

## 4. 작성 전 체크리스트

- [ ] 헤드라인이 4유형(정체성/변환/지표/자산-방향) 중 하나인가? 완결 문장이 아닌가?
- [ ] 서브 첫 문장이 현재형 단정인가?
- [ ] 카드 본문이 정확히 한 문장이고 괄호 실물 예시가 있는가?
- [ ] 불릿에 마침표가 없고 숫자가 문두에 있는가?
- [ ] 지표 밴드가 4개 단위로 묶였고, 숫자에 시점·축약 표기가 있는가?
- [ ] 진행 상태가 배지/각주로 구분되어 있는가? (NDA / In Progress / Planned)
- [ ] 콘셉트 용어의 표기가 문서 전체에서 동일한가?
