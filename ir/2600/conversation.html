API/외부 연동 가능한 서비스들

1. Midjourney (제한적)

공식 API는 없지만 비공식 Discord Bot API를 통해 자동화 가능. --cref (Character Reference) 기능으로 동일 인물 일관성 매우 우수

2. Stability AI (Stable Diffusion API)

공식 REST API 제공 → ChatGPT, Claude MCP 연동 직접 가능. IP-Adapter, ControlNet 활용 시 얼굴 일관성 높임

3. fal.ai

다양한 모델을 API로 제공 (FLUX, SD 등). FLUX.1 Kontext 모델 → 동일 인물 일관성에 최근 매우 강해짐. Claude/GPT Function calling으로 바로 연동 가능 ✅

4. Replicate

수백 개 모델을 REST API로 제공. Face LoRA, IP-Adapter 등 얼굴 고정 모델 다수 보유. Vibe coding 연동 매우 쉬움 ✅

5. Piapi.ai / GoAPI

Midjourney, FLUX 등을 API로 래핑해서 제공. 공식 API 없는 서비스들의 대안 ✅

동양인 이미지 품질 순위

🥇 1위 - Midjourney (v6.1+)
동양인 표현이 자연스럽고 피부톤, 이목구비 왜곡 거의 없음. --cref로 인물 일관성까지 잡으면 현재 최고 수준. 단점: 공식 API 없음

🥈 2위 - fal.ai (FLUX.1 계열)
FLUX는 서양 중심 데이터 편향이 SD 대비 적은 편. Kontext 모델에서 동양인 얼굴 재현 준수. API 연동 용이 ✅

🥉 3위 - Leonardo.ai
PhotoReal 모드에서 동양인 피부톤 표현 양호. 단, 눈 묘사가 가끔 서구화되는 경향

동양인에 특화된 숨은 선택지

Kolors (쾌수) — 중국 쾌수(快手)가 만든 모델, 동양인 실사 이미지 특화. Replicate나 fal.ai에서 API로 사용 가능 ✅
