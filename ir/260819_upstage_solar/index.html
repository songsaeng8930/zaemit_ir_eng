강점 · 한국어 특화

한국어 콘텐츠 생성

글로벌 모델의 한국어 카피는 지금 대표가 직접 다듬는 구간입니다. 존댓말과 업종 용어를 Solar가 바로 쓰게 해, 모든 사이트의 문구 품질을 끌어올립니다.

강점 · $0.03 / 1M 토큰

RAG 연동 지능형 챗봇

예약·주문·게시글 같은 운영 데이터를 읽고 방문자의 실시간 요청에 답하는 RAG 챗봇입니다. 응답이 잦은 구간이기 때문에, Solar의 단가가 그대로 원가 경쟁력이 됩니다.

세 곳 모두 지금의 Solar Pro 4로 구현하거나 대체 가능한 범위입니다. 국내 사업자를 위한 서비스는 국산 재료로 마감하고 싶습니다.

확장 로드맵

앞 장의 세 자리에서 실측 품질이 확인되는 순서대로 진행하는 개발 계획입니다.
1단계 · 검수

생성 HTML 전수 검수

생성된 사이트의 HTML 전체를 Solar가 읽고 문구·구조·누락을 검수하는 기능을 개발할 예정입니다. 524K 컨텍스트로 사이트 전체를 한 번에 읽을 수 있기 때문에 가능한 기능입니다.

2단계 · 생성

에이전트 결합, 생성까지 확대

Zaemit의 디자인시스템은 지침뿐만 아니라 샘플 코드를 전송하는 방식으로 스킬 이상의 높은 품질을 만들어 낼 수 있습니다. 웹 제작을 대행하는 Zaemit의 5개 에이전트에 Solar를 결합해 보겠습니다. 

3단계 · 데이터 축적 후

Living DB 운영 자동화

예약·주문·방문 통계가 쌓이면, 그 데이터를 근거로 운영 개선을 먼저 제안하고 사용자 요청을 처리하는 시스템까지 Solar에 맡길 수 있다고 봅니다. RAG 데이터가 축적된 뒤의 단계입니다.

스타트업과 소상공인에 그치지 않고, G-Cloud 기반 공공 SI 까지 위의 서비스를 모두 필요로 합니다. WEVEN은 관련 R&D를 성공/추가 수행 중입니다.
