## 자료별 해석 범위

**Klarna**: 230만 건과 상담원 700명에 해당하는 업무량은 회사가 발표한 첫 달 수치이며, 700명은 해고 인원이 아닙니다. 2025년의 80%는 연간 공시 수치로 집계 기간이 다르므로, 첫 달의 약 3분의 2와 같은 조건의 개선율로 비교할 수 없습니다. 사람 상담을 강화했다는 사실도 AI 사용 중단과 구분해야 합니다.

**BCG**: 2026년 정식 출판본(DOI 10.1287/orsc.2025.21838)을 사용했습니다. 본문 11쪽의 정답률은 84.5%, 70.6%, 60.0%이며 한 과제의 결과입니다. 이를 모든 AI 교육의 효과로 해석할 수는 없고, 완료 시간·과제 수·정답률도 서로 다른 지표로 구분해야 합니다.

**Anthropic**: Claude 이용 기록에서 분석한 업무 분포이므로 전체 노동시장의 AI 도입률이나 자동화 가능한 업무 비율로 해석할 수 없습니다. 업무의 25%라는 값을 기업의 도입 기준으로 제시하지 않았습니다.

**Copilot**: 55.8%는 JavaScript HTTP 서버 구현 과제에서 측정한 완료 시간 단축률입니다. METR 실험과 참가자·과제·도구·시점이 달라, 두 결과만으로 도구의 성능 순위를 정하거나 숙련도 차이의 효과를 설명할 수는 없습니다.

**METR**: 2025년 초 도구를 사용한 개발자 16명과 실제 개발 작업 246개의 결과입니다. 측정한 시간은 19% 늘었고, 작업 후 참가자는 20% 단축됐다고 추정했습니다. 두 값은 별도의 지표이므로 39%포인트로 합산해서는 안 됩니다. 2026년 후속 자료도 참여·작업 선택에 따른 편향과 측정의 어려움을 다루고 있으므로, 과거 결과를 현재 모든 도구에 그대로 적용할 수는 없습니다.

**Replit**: 개발용 데이터베이스와 운영용 데이터베이스를 분리했다는 공식 발표를 사용했습니다. 확인하지 못한 사고의 세부 수치와 에이전트 발언은 제외했습니다.

**Air Canada**: 2024 BCCRT 149에 대한 ABA 해설을 참고했습니다. 캐나다의 특정 분쟁에 대한 판단이므로, 한국 법률이나 모든 챗봇 발언의 효력에 관한 일반 규칙으로 설명할 수는 없습니다. 슬라이드의 대화는 사건 요약을 재구성한 문장이며 실제 대화의 직접 인용이나 화면 캡처가 아닙니다.

**Generative AI at Work**: arXiv v2(2024-11-06)의 상담원 5,172명과 시간당 해결 건수 15% 증가를 사용했습니다. 초고의 5,179명·14%와 구분했으며, 단계적 도입을 분석한 현장 연구이므로 무작위 실험으로 설명해서는 안 됩니다.

**발표자 경험**: 발표자가 제공한 경력과 제품 구조를 바탕으로 작성했습니다. 내부 성과가 AI 때문에 증가했다고 입증되지 않은 주장은 제외했습니다.

## 가상 예시와 운영 제안

세미나 업무와 화면·대화는 교육용으로 가정한 예시입니다. 하루 초안 100건과 검토 20건, 작업 시간 40분과 37분, 월 100건·시간당 3만 원·도구비 20만 원도 계산을 위한 가정이며 실제 성과가 아닙니다. 월 10시간 절약은 앞의 비용 계산과 별개인 예시입니다.

검토 기준, 실행 권한, 교육 절차, 2주 시험 운영은 사례를 참고한 강의의 제안입니다. 논문에서 직접 검증한 운영법이나 실제 디모아의 업무 현황, 재밋에 구현된 기능으로 설명해서는 안 됩니다.

## 수치와 인용의 편집 기준

서로 다른 지표를 같은 의미로 비교하거나, 특정 조건의 결과를 모든 업무에 적용하는 설명은 제외했습니다. 이에 따라 MIT NANDA의 95%, Gartner의 30%, 거시 생산성 0.66%를 같은 지표처럼 비교하던 내용과 업체 자체 비교의 수정 토큰 20~50배를 일반화하던 내용을 삭제했습니다. 구매 67%·자체 개발 33%도 모든 기업에 적용되는 선택 기준으로 사용하지 않았습니다.

국가가 다른 고용·공고 수치의 단순 비교, 직접 확인하기 어려운 미래 코드 비중과 유명인 발언도 제외했습니다.
